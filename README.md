## Intended users

Z9D-SRS v5.3 PRO is intended for:

- individual robots and industrial automation units;
- ground-control laptops and command stations;
- autonomous and AI-assisted robotic systems;
- drones and unmanned vehicles;
- OEM integrations and approved fleet deployments.

## Main functions

- monitoring of running processes;
- analysis of active network connections and remote IP addresses;
- review of security-related Windows events;
- process and network risk indicators;
- quarantine and incident reporting;
- wireless-transport monitoring;
- license, activation and device-ID management;
- pairing for twin systems and control clusters.

The exact feature set depends on the delivered edition and license.

## Supported communication paths

The product can be configured for relevant communication paths such as:

- Wi-Fi / WLAN;
- Bluetooth;
- radio;
- infrared;
- cellular links;
- Ethernet;
- telemetry and other platform-specific transports.

## License models

| Model | Scope |
|---|---|
| `SingleRobot` | One robotic unit |
| `TwinRobotControl` | One robot node and one paired control node |
| `ControlMultiRobotPack` | One control node and multiple robot units |
| `RobotPack / OEM` | Managed packs for OEM and fleet deployments |

Product families include SRS Remote, SRS Autonomous, SRS AI and SRS Universal OEM.

## Device roles

- `ROBOT_NODE`: the robot, vehicle or autonomous unit;
- `CONTROL_NODE`: the laptop, PC, server or command station operating or monitoring the robot;
- `MOBILE_CONTROL`: a supported mobile or field-control profile;
- `OEM_NODE`: an approved profile for a manufacturer deployment.

Role selection should match the actual system being licensed.

## Pairing and clusters

### Single node

Use a single-node license when only one unit needs authorization.

### Twin system

Use pairing for a robot and its dedicated control station. Both devices should be entered with the correct device IDs.

### Control cluster

Use a control-cluster package when one authorized control node manages multiple target systems. Enter the complete, accurate list of target units.

## Start procedure

1. Download the official archive.
2. Extract the package to a dedicated folder.
3. Start the supplied executable.
4. Record the displayed device ID.
5. Select the product and manufacturer profile.
6. Set the correct node role.
7. Enter paired device IDs or target robot units when required.
8. Submit the license request and wait for authorization.
9. Reopen or refresh the application if needed, then verify activation and pairing status.

Do not modify, rename or replace protected license and server configuration files.

## Installation and operating notes

- Z9D-SRS v5.3 PRO is designed for Windows systems.
- No public source code or administrator configuration is included.
- Network, firewall and antivirus policies may affect activation or monitoring.
- A local or VPN-based infrastructure can be required for corporate and OEM deployments.
- No product can guarantee protection against every attack or future unknown threat.

## Responsible use

Use Z9D-SRS only on systems you own or are authorized to operate. Do not use the software to interfere with third-party devices, civil infrastructure or unauthorized communication paths.
